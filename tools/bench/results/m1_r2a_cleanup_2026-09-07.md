## 4. 变异检验（证明这些断言真的有牙）

在 scratch 里复制一份源码再改，**不动项目目录**：

```bash
MUT=~/Library/Caches/brosis-build/m1-cleanup-app/mutation

rsync -a --exclude .build --exclude .swiftpm <项目目录>/app/  "$MUT/app/"

  swift build --package-path "$MUT/app" --scratch-path "$MUT/build" -c release
```

本轮实跑：六处一起改回旧写法后 **退出码 1、恰好 6 项 FAIL**，一一对应：

| 改回什么（在 scratch 副本里） | 期望 FAIL 的那一项 |
|---|---|
| `isEventTrigger` → `reason != "periodic"` | 截图触发口径（`queued` / `periodic+queued` 期望 false） |
| `depthLimitHit` → 只看 `depth >= maxDepth` | AX 深度上限（"到上限但是叶子：不算命中"） |
| `Recorder` 退回 `pendingNotes` 方案 | recorder_dropped 时序（解锁后 jobs 还是 1，没多那一行） |
| `cancelsDeferredUnlock(.screenLocked)` → 恒 `true` | 锁定类触发取消补做（`screenLocked(strict=false)` 期望"不取消"） |
| `setPaused` 无条件记事件 | setPaused 只在状态变化时写事件（0 → 2、2 → 5） |
| `StatsExport` 写 `dbstat: []` | 存储统计导出 JSON（`dbstat 0 项`） |

出处：`m1-cleanup-app/results/selfcheck_mutated.txt`。

## 6. 对计划的影响

一句话：**计划本身不用改**——这一轮全是口径与工程性修正；唯一对后续任务有影响的是
`stats-<日期>.json`（`schema_version=1`）现在是 M1 R2 月报脚本（T6）读取存储行数字的**唯一稳定入口**，
另外 `core` 去掉 `unsafeFlags` 之后，将来把它拆成独立仓库 / 按版本引用不再需要额外改造。
